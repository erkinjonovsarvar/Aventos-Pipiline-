# Executive Analytics Dashboard

Interaktiv korporativ moliyaviy dashboard. Loyiha HTML, CSS va JavaScript asosida yaratilgan bo'lib, asosiy moliyaviy ko'rsatkichlarni va grafiklarni bitta sahifada ko'rsatadi.

## Dashboard imkoniyatlari

- Jami tushum ko'rsatkichi
- Sof foyda ko'rsatkichi
- Operatsion xarajatlar
- Mijozlar soni
- Oylik daromad va xarajatlar dinamikasi
- Xarajatlar tarkibi
- Sof foyda trendi
- Filiallar kesimida sotuvlar
- Yil, oy, valyuta va filial filtrlari
- UZS va USD formatida ko'rish
- Responsive dizayn

## Ishlatilgan texnologiyalar

- HTML5
- CSS3
- JavaScript
- Chart.js
- Google Fonts (Inter)

## Ishga tushirish

Loyiha bitta `index.html` fayldan iborat.

1. Repository'ni yuklab oling yoki clone qiling.
2. `index.html` faylini brauzerda oching.
3. Dashboard ishlashga tayyor.

Qo'shimcha server yoki backend talab qilinmaydi.

## Ma'lumotlar haqida

Dashboard hozircha demo/simulyatsiya qilingan ma'lumotlar bilan ishlaydi. Filtrlar o'zgartirilganda ko'rsatkichlar qayta generatsiya qilinadi. Haqiqiy loyiha uchun ma'lumotlar API, database yoki boshqa ma'lumotlar manbasidan ulanishi mumkin.
